Markify

Privacy Policy

Markify does not collect, transmit, or store any personal data. All PDF conversion happens locally in your browser. Your documents never leave your device.

Data accessed

Markify accesses the following data only when you click the extension icon:

  • Active tab URL — checked to determine if the current page is a PDF file (URL ending in .pdf).
  • PDF file content — the PDF binary data is fetched and processed entirely within your browser to extract text content.

Data stored

Markify stores the following data locally in your browser's extension storage:

  • Conversion history — when you click "Save", the converted Markdown text, source URL, page range, and timestamp are saved locally. Up to 100 entries are retained.

This data is stored using the Chrome Storage API (chrome.storage.local) and never leaves your device. You can delete individual entries or clear all history from within the extension.

Data collected

None. Markify collects zero analytics, zero telemetry, and zero usage data. There are no tracking pixels, no cookies, and no fingerprinting.

External servers

Markify makes no network requests to external servers. The only network activity is fetching the PDF file from the URL already open in your browser tab. No data is sent to any third-party service.

Third-party services

Markify uses no third-party services. The PDF text extraction is performed using pdf.js, an open-source library by Mozilla, which runs entirely client-side.

Permissions explained

Permission Why it's needed
activeTab To detect whether the current tab contains a PDF and to read the PDF URL for conversion. Only activates when you click the extension icon.
storage To save your conversion history locally within the browser. No data is synced or transmitted.
